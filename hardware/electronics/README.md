# Electronics artifacts

← [electronics write-up](../../docs/electronics.md)

**This directory is currently empty of diagrams.**

The modified wiring diagram — reflecting the converters and peripherals I actually
sourced, rather than the parts the original bill of materials specifies — is not yet
available. It belongs here, committed as the original artifact (PDF or image, as drawn),
with a note on what changed relative to the original wiring architecture.

Upstream's original schematic and wiring pictogram are **not** reproduced here. They are
Chris Locke's documents and are available from
[the upstream project](https://github.com/cguweb-com/Arduino-Projects/tree/main/Nova-SM3).

What *is* documented, and verified against hardware, is the pin map — see the bring-up
table in [`docs/electronics.md`](../../docs/electronics.md), which reflects the pins
each subsystem was actually tested on.
